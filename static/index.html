Calibrate strings

So the app can tell which string you play a note on (D on A5 or the open D). Tune to standard (E A D G). For each spot, play the note 8 times the way you'd play it in a song, some quick, some held; it moves on by itself. About 4 minutes; Save works part way too.

Calibrate timing

Play each note as it reaches the line, in time with the clicks: 4 clicks count you in, then 16 notes. Only the timing counts, so a wrong note is fine.
